Babji Flow

A free, local-first voice keyboard and meeting notetaker for macOS. Same feel as Wispr Flow, no subscription, your audio never leaves the Mac unless you ask Claude to summarize a meeting.

Flow spells the way you do. Babji Flow types the way you do.

Hold a key, talk, release. Clean text lands in whatever app is focused, in your style, with your words spelled right. Open a call and it offers to take notes.

1. What we are building

Voice keyboard

  • Hold fn (or a chosen key) to dictate into any app
  • Notch pill at the top of the screen shows listening, thinking, done
  • Filler removal, self-correction handling, auto punctuation, lists, paragraphs
  • Spoken commands: "new line", "new paragraph", "bullet point", "scratch that"

Dictionary that learns

  • Manual entries: names, jargon, product names
  • Auto-learn: after you paste, Babji reads the field back and diffs. If you corrected a word, it proposes a dictionary entry (sparkle = learned)
  • Entries feed both dictation and meeting transcripts

Style per app

  • Personal messages, Work messages, Email, Other
  • Formal / Casual / Very casual (no caps, less punctuation)
  • App is detected by bundle ID (WhatsApp, Telegram, Discord, Slack, Mail, ...)
  • Auto cleanup toggle and a custom "how I write" sample

Insights

  • Words dictated, time spoken, words per minute
  • Time saved vs typing at 40 wpm, streak, top apps
  • Daily chart for the last 30 days

Notetaker

  • "Meeting detected" bar appears when another app opens your mic
  • Records mic + system audio, diarizes speakers locally
  • Summary: overview, themed sections, next steps, decisions
  • Full transcript with speakers and timestamps, rename speakers
  • Chat with the transcript ("what did they ask me to do?")

Menu bar + settings

  • Lives in the menu bar, no dock icon by default
  • Settings: hotkey, model, style, Claude API key, permissions
  • All data in ~/Library/Application Support/BabjiFlow as JSON

2. Model choice: which speech model, and why

You asked for the "fluid voice model". That is FluidAudio, a Swift package from FluidInference that runs NVIDIA's Parakeet models as CoreML on the Apple Neural Engine. It is free, offline, and fast on an M2 with 8 GB. It also ships speaker diarization and voice activity detection, which is exactly what the notetaker needs.

ModelLanguagesSizeVerdict
Parakeet TDT 0.6B v2English only~600 MBRecommended for you Best English accuracy and recall. Trained on 120k hours of English. Best at casual speech, names, Indian-English accents in our testing notes.
Parakeet TDT 0.6B v325 European languages~600 MBAvailable in settings Use if you dictate in other languages. Slightly lower English accuracy than v2.

Default: v2. You can switch to v3 in Settings; the model is downloaded once from HuggingFace and cached.

Text cleanup ("the Wispr magic")

Raw STT output is not what you want typed. A three-layer pipeline turns it into clean text:

Parakeet raw text→ Rules: fillers, commands, self-corrections, numbers→ Dictionary replacements→ LLM polish in your style→ Paste
Polish engineCostWhen used
Apple Foundation Models (on-device, macOS 26)FreeDefault when Apple Intelligence is enabled. Handles punctuation, casing, style, list formatting.
Claude API (Opus 5)Paid, your keyOptional for dictation. Required for meeting summaries and transcript chat (transcripts are too long for the on-device model's 4k context).
Rules onlyFreeFallback if neither is available. Still removes fillers, applies commands and dictionary.

3. The notch

Listening…

A borderless, always-on-top NSPanel anchored to the top center of the screen, drawn in black with rounded bottom corners so it looks like it slides out of the physical notch. States: idle (hidden), listening (live level bars from the mic), processing (spinner), done (checkmark then hides), and the meeting-detected state (red dot, "Record" and "Dismiss" buttons).

Key mechanisms

  • Hotkey: a global flagsChanged tap catches fn / right option. Hold to talk, release to finish. Requires Accessibility permission (the app guides you to it).
  • Paste: saves your clipboard, writes the text, sends Cmd-V, restores the clipboard after 300 ms.
  • Auto-learn: 4 seconds after pasting, the focused text field's value is read through the Accessibility API and word-diffed against what was pasted. A replaced word with small edit distance becomes a learned dictionary entry (marked with a sparkle, one-click to delete).
  • Meeting detection: CoreAudio property kAudioDevicePropertyDeviceIsRunningSomewhere on the default input flips true when Zoom, Meet, FaceTime, etc. open the mic. Babji ignores its own sessions.
  • Meeting audio: mic via AVAudioEngine, other apps via ScreenCaptureKit (needs Screen Recording permission). Both resampled to 16 kHz and mixed. Diarization runs on the mixed track after the meeting ends; each transcript segment is assigned the dominant speaker.
  • Summary: Claude Opus 5 with a JSON output schema: title, overview, sections (heading + bullets), next steps (owner + action), decisions. Prompted to be terse and factual like your sample.
  • Chat: transcript is placed in the system prompt with prompt caching so follow-up questions are cheap.

6. Build phases

Skeleton + notch + dictation loop. Package, app bundle script, menu bar, hotkey, mic capture, Parakeet v2 transcription, paste. Rule cleaner and dictionary.
2
Style + LLM polish + auto-learn. Style presets per app category, Foundation Models polish, Claude fallback, Accessibility read-back learner, Insights store.
3
Notetaker. Mic activity monitor, meeting bar, recorder with system audio, diarization, Claude summary and chat, Notetaker UI.
4
Polish. Settings, onboarding for permissions, first-run model download progress, README.

7. Running it

./build.sh          # builds BabjiFlow.app into ./build
open build/BabjiFlow.app
# first launch downloads Parakeet v2 (~600 MB) and shows progress in the notch

Claude API key: paste it in Settings. It is stored in the macOS Keychain. Without it, dictation still works fully; meeting summaries and chat show a prompt to add the key.
